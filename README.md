# Slika releases

Installers and update files for **Slika**, a fast photo catalogue for Windows.

Slika checks this page for new versions. Each release has the Windows installer, a short note on what's new,
and a small version file (`latest.json`) that Slika reads to know an update is ready. Every update is signed,
and Slika checks that signature before installing anything.

Slika is in beta. Problems or questions: hello@tryslika.com, or use **Help › Report a problem** in Slika.

This page holds only the releases. Slika's source code isn't published here.
